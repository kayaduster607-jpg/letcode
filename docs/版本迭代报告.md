### 2.4 修正「两数相加」参考代码

**修改文件**：`src/data/problems.ts`

原实现通过链表转整数再转链表来求解，不适合作为教学标准解法。已改为标准逐位相加写法：

```typescript
// 修正后：dummy + carry + while l1 or l2 or carry
const dummy = new ListNode(0);
let curr = dummy;
let carry = 0;
while (l1 || l2 || carry) {
  const sum = (l1?.val ?? 0) + (l2?.val ?? 0) + carry;
  carry = Math.floor(sum / 10);
  curr.next = new ListNode(sum % 10);
  curr = curr.next;
  l1 = l1?.next;
  l2 = l2?.next;
}
return dummy.next;
```

## 6. v2.2.0 - 测试修复与稳定性提升

### 6.1 新增全局 404 页面

**新增文件**：`src/app/not-found.tsx`

新增全局 `not-found.tsx`，用户访问不存在的路由时展示友好的 404 页面，而非 Next.js 默认的错误页。

### 6.2 题目详情页拆分客户端组件

**新增文件**：`src/app/problem/[slug]/ProblemClient.tsx`
**修改文件**：`src/app/problem/[slug]/page.tsx`（152 行变更）

将题目详情页的状态逻辑抽取为独立的 `ProblemClient` 客户端组件，`page.tsx` 作为 Server Component 负责路由参数解析。解决了以下问题：

- 修复了客户端 hooks（useState/useEffect）在 Server Component 中的报错
- 题目未找到时展示专属 404 页面（`not-found.tsx`）而非内联错误信息
- 代码结构更清晰，符合 Next.js App Router 最佳实践

### 6.3 新增 QA 自动化脚本

**新增文件**：`scripts/qa_hot100.py`、`scripts/refine_hot100.py`

| 脚本 | 用途 |
|------|------|
| `qa_hot100.py` | 自动检查 100 道题的数据完整性：slug 唯一性、必填字段、外部链接有效性等 |
| `refine_hot100.py` | 批量精修题目数据的辅助脚本 |

`package.json` 新增对应命令：

```json
"qa:content": "python3 scripts/qa_hot100.py",
"verify": "npm run lint && npm run qa:content && npm audit --audit-level=moderate && npm run build"
```
