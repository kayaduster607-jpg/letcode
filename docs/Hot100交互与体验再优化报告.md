# Hot100 交互与体验再优化报告

## 本轮用户反馈

用户指出三类问题：

1. 字体不标准，页面中文字一大一小，视觉不统一。
2. 六步学习展开后不能收起，影响继续阅读。
3. 学习流程不能停留在“题目/问题”，写完题后还需要自测、纠错、复盘和面试复现。
4. `pnpm dev` 控制台出现 Next.js 的 `scroll-behavior: smooth` 提示。

## 已修复内容

### 1. 字体和阅读宽度

- 将问题详情页的字体统一为系统常见中文字体栈：Arial、微软雅黑、苹方、思源黑体等。
- 收敛问题详情页字号层级：正文约 15.5px，模块标题 20px，题目标题 30–36px。
- 降低 `font-black` 的过粗渲染，避免中文字体被浏览器强行加粗导致发虚。
- 限制详情页主内容最大宽度，避免在 2K / 4K 屏幕上单行文字过长。
- 优化代码块字号、行高、头部标签和复制按钮，避免 `pseudo` / `python` 标签过小。

### 2. 六步学习可展开也可收起

修改 `src/components/GuidedStepCard.tsx`：

- 解锁状态与展开状态分离。
- 点击已解锁步骤可以收起/展开。
- `展开全部解答` 在全部展开后会变为 `收起全部`。
- 收起不会清除学习进度；已经解锁的答案仍保持解锁，只是折叠展示。

### 3. 伪代码展示方式优化

修改 `src/components/SolutionWalkthrough.tsx`：

- 伪代码 / 流程不再用深色代码块展示。
- 改成轻量步骤列表，降低视觉噪音。
- 真正的 Python 参考代码仍保留深色代码块和复制按钮。

### 4. 新增“写完题后的解决闭环”

新增 `src/components/PostSolveCoach.tsx`，并接入题目详情页。

该模块让每道题在“看完答案”后继续完成：

- 提交前自测清单。
- 至少 3 个边界样例验证。
- 常见错误的定位方式。
- 常见错误的修正方式。
- 修完后的再测试策略。
- 小白到面试手撕的复盘路径。

该模块不是单纯提问，而是给出“定位—修正—再测”的具体操作。

### 5. 修复 Next.js dev 提示

修改 `src/app/layout.tsx`：

```tsx
<html lang="zh-CN" data-scroll-behavior="smooth">
```

用于匹配项目中 `html { scroll-behavior: smooth; }` 的设置，消除开发环境浏览器控制台提示。

### 6. Windows / pnpm 体验优化

新增跨平台 Node QA 脚本：

```text
scripts/qa_hot100.mjs
```

并将 `package.json` 中的内容 QA 改为：

```json
"qa:content": "node scripts/qa_hot100.mjs"
```

这样 Windows 用户不用依赖 `python3` 命令也能跑内容校验。原 Python 深度脚本仍保留为：

```json
"qa:python": "python scripts/qa_hot100.py"
```
