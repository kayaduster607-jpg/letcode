# Hot100 学习助手 - 网站与解题学习优化报告

## 一、本次优化目标

原始问题集中在两点：

1. **网站层面**：题目列表、首页推荐和学习路线都会跳转到 `/problem/[slug]`，但项目缺少题目详情页，用户点进题目后无法进入完整学习流程。
2. **学习层面**：原来的学习设计偏“提问式提示”，小白用户容易只看到问题，不知道下一步应该怎样想，也缺少从暴力解法到最优解法的完整参考答案。

本次优化围绕“代码随想录式教学”重构为：

> 读题建模 → 暴力起步 → 定位瓶颈 → 识别模式 → 写伪代码 → 对照完整代码 → 复杂度 / 错题 / 复盘

## 二、网站优化

### 1. 补齐题目详情动态路由

新增文件：

```text
src/app/problem/[slug]/page.tsx
```

解决的问题：

- 首页「开始学习」可以正常进入题目详情页。
- 学习路线题目列表可以正常跳转。
- 学习路径卡片可以跳转到当前阶段的代表题。
- 侧边栏支持返回学习路线、下一题、LeetCode 原题链接。

### 2. 题目详情页结构优化

详情页现在分为主内容区和右侧学习侧栏：

- 顶部题目卡片：题号、标题、英文名、难度、题型、标签。
- 学习目标：说明这道题要掌握什么能力。
- 小白六步学习：逐步解锁提示与参考答案。
- 题型方法论：按题型展示对应套路。
- 完整解题拆解：暴力、优化、伪代码、完整代码。
- 复杂度分析：优先读取题目数据，否则从解法描述提取或给出题型级参考。
- 常见错误与复盘问题：帮助用户把题目沉淀成可迁移模板。
- 我的笔记：保留本地笔记能力。

### 3. 学习路线页增加“如何学习”说明

修改文件：

```text
src/app/learn/page.tsx
```

新增三个学习模式卡片：

1. 先独立思考。
2. 卡住再解锁。
3. 最后复盘迁移。

这能降低新手进入路线页后的理解成本，让用户知道不是机械刷题，而是按步骤训练解题思维。

### 4. 修复开发脚本

修改文件：

```text
package.json
```

原来的 `next lint` 在当前 Next.js 版本下不可用，会被识别成错误的项目目录。本次改为：

```json
"lint": "tsc --noEmit",
"typecheck": "tsc --noEmit"
```

现在可以通过 TypeScript 检查验证项目基础正确性。

## 三、解题学习优化

### 1. 六步学习不再“只有问题”

修改文件：

```text
src/components/GuidedStepCard.tsx
```

原来每一步主要是问题和提示。现在每一步都有：

- 思考问题：先让用户自己想。
- 思考引导：告诉新手应该从哪个角度切入。
- 参考解答：给出这一层的答案。
- 完整代码：最后一步直接展示参考实现。
- 一键展开全部解答：避免用户想直接看答案时找不到。

六步结构：

| 步骤 | 目的 |
|---|---|
| 1. 读题建模 | 把题目翻译成人话，确认输入、输出、限制条件 |
| 2. 暴力起步 | 先保证能解，再谈优化 |
| 3. 定位瓶颈 | 找到暴力为什么慢 |
| 4. 识别模式 | 解释为什么该题适合当前题型方法 |
| 5. 落到流程 | 用伪代码降低直接写代码的难度 |
| 6. 完整答案 | 对照代码、复杂度和边界条件复盘 |

### 2. 增加完整解题拆解组件

新增文件：

```text
src/components/SolutionWalkthrough.tsx
```

该组件把题目学习内容拆成：

- 题目本质。
- 暴力解法。
- 优化突破口。
- 伪代码 / 流程。
- 参考代码。
- 复杂度分析。
- 常见错误。
- 复盘问题。

这样用户不需要只靠提示猜答案，能看到完整路径。

### 3. 扩展题型方法论

修改文件：

```text
src/components/MethodologyCard.tsx
src/lib/constants.ts
```

覆盖了项目中的全部题型：

- 哈希
- 双指针
- 滑动窗口
- 链表
- 二叉树
- 回溯
- 贪心
- 动态规划
- 多维动态规划
- 二分查找
- 栈 / 单调栈
- 堆
- 图论
- 普通数组
- 矩阵
- 子串
- 技巧

每种题型都按“什么时候想到、变量含义、核心流程、常见坑”的方式讲解，更接近代码随想录的模板化学习方式。

### 4. 修正代表题「两数相加」参考代码

修改文件：

```text
src/data/problems.ts
```

原数据里「两数相加」的完整代码是“链表转整数再转链表”，与前面讲的逐位模拟竖式加法不一致，也不适合教学迁移。本次改为标准链表逐位相加写法：

- 使用 dummy 节点。
- 使用 carry 处理进位。
- `while l1 or l2 or carry` 覆盖不同长度和最后进位。
- 复杂度改为 `O(max(m,n))`。
